# ☕ CafeFinder

CafeFinder is a responsive location-based web application that helps users discover nearby cafes using real-time location data.

## ✨ Features

- 📍 Detect the user's current location
- ☕ Discover nearby cafes
- 🗺️ Interactive map with cafe markers
- 🔍 Search cafes by name
- ↕️ Sort cafes by distance or name
- ❤️ Save favourite cafes using localStorage
- 📌 Show individual cafes on the map
- 🧭 Open directions in Google Maps
- 📱 Responsive desktop and mobile design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Geoapify Places API
- Leaflet.js
- OpenStreetMap
- Browser Geolocation API
- localStorage

## 🚀 How It Works

CafeFinder uses the browser Geolocation API to retrieve the user's current coordinates.

The coordinates are sent to the Geoapify Places API to search for nearby cafes.

The results are dynamically displayed as cafe cards and markers on an interactive Leaflet map.

Users can search and sort cafes, save favourites locally, focus cafes on the map, and open directions.
